# D-Day: squad tactics

Bryan's D-Day game. It began as a test level inside the horror game (Warehouse Yard, the repository's root) and was split off after Version 157: this folder has its own copy of everything (`index.html`, `css/`, `js/`, `sounds/`), and the two games share no files. A fix wanted in both has to be made in both.

- Page: `index.html` (its start card has only D-Day; the other game's buttons are kept hidden in it because the copied scripts still bind to them). Published at its own link.
- The copied horror-game scripts (levels, monsters, the HQ...) are still loaded but nothing reaches them. Stripping them out is still to do, file by file.
- No recorded voices here (`voice.js`'s loaders return at once; `sounds/` has the gunfire and effects only).
- Notes, Bryan's answers and the drafts: `docs/dday-test.md`, `docs/drafts/`. Draft tools: `tools/drafts/` (run from the scratchpad harness with `REPO` pointing at this folder).
- Working rules are the root `CLAUDE.md`'s (plain scripts in one global scope, load order set in the page, no build step; testing notes).
